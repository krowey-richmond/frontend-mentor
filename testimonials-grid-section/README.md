## 📌 Overview

This challenge focuses on building a responsive testimonial layout using CSS Grid.
The goal is to match the design as closely as possible while maintaining semantic HTML and clean structure.

Key objectives:

* Implement a multi-column responsive grid layout
* Use semantic HTML elements
* Maintain consistent spacing and typography
* Apply proper color contrast
* Ensure responsive behavior across breakpoints

---

## 🛠️ Built With

* Semantic HTML5
* CSS Custom Properties
* CSS Grid
* Mobile-first workflow
* Google Fonts (Barlow Semi Condensed)

---

## 🧠 What I Learned

* How to control complex grid layouts using `grid-template-areas` and manual grid positioning
* Using CSS variables for scalable color management
* Structuring responsive layouts with multiple breakpoints
* Managing component spacing consistently with flexbox inside grid items

This project reinforced layout control and responsive thinking.
